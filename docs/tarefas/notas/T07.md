## Como testar com hardware real

1. Depois que `raizad` estiver compilado (T04+), instale o binário em `/usr/bin/raizad` e copie os arquivos conforme [`docs/INSTALACAO.md`](../../INSTALACAO.md).
2. Carregue o módulo `i2c-dev` (`sudo modprobe i2c-dev`) caso vá usar DDC/CI.
3. Recarregue as regras udev:
   ```sh
   sudo udevadm control --reload && sudo udevadm trigger
   ```
   (Se necessário, reconecte os dispositivos USB/dongle.)
4. Confirme que os nós `/dev/hidraw*` dos dispositivos listados e `/dev/i2c-*` receberam ACL `rw-` para o usuário atual (e que outros dispositivos `hidraw`, como o microfone `3142:a010` e a interface HID do monitor `043e:9a39`, **não** foram liberados pela regra):
   ```sh
   getfacl /dev/hidraw* /dev/i2c-*
   ```
5. Habilite e suba o daemon na sessão do usuário e confirme que ele adquiriu o nome no D-Bus:
   ```sh
   systemctl --user daemon-reload
   systemctl --user enable --now raizad
   systemctl --user status raizad
   busctl --user status io.github.yurileo01.Raiza
   ```
